# Cat game builds

I’m a software developer making my first game. It’s a strange cat game about
getting home while the night gets worse.

When a piece is worth sharing, I put a playable build here.
[Play the latest build](https://sammygp.github.io/midnight-cat-web/).

The current one is the normal first-level build, packaged for the browser without
Web-only gameplay changes. The House Cat uses two walk frames while moving and
the original sprite while standing still. Move with WASD, Pounce with Space, and
deal with eighteen Rats while Claw Swipe fires on its own.

It’s still rough: prototype House Cat art, placeholder enemies, and no full run
yet.
