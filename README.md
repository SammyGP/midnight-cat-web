# Cat game builds

I’m a software developer making my first game. It’s a strange cat game about
getting home while the night gets worse.

When a piece is worth sharing, I put a playable build here.
[Play the latest build](https://sammygp.github.io/midnight-cat-web/).

The current one is a small combat checkpoint about damage, death, and restart.
Move with WASD, Pounce with Space, and deal with eighteen Rats while Claw Swipe
fires on its own.

It’s rough: prototype cat art, placeholder enemies, and no full run yet.
